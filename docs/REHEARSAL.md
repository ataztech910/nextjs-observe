на самом деле (план в скобках).

## Находки

- **1.2 · значок Next.js «3 issues».** В dev-режиме Next сам показывает 3 из 6 ошибок. Варианты: (а) обыграть — «в dev видно три, в проде пользователи не видят ни одной, а всего их шесть»: строка в заметке слайда `no-errors`; (б) `devIndicators: false` в `next.config.ts` магазина — меняет теги. Решение автора: (а) — обыграть, строка в заметке `no-errors` (сделать после репетиции).
- **2.2 · подпись слайда.** В нижней строке «Your turn · write the receiver», а задание — дописать чтение пачки, сервер готов. Автор на репетиции понял как «писать сервер». Подпись → «Your turn · your own receiver» (сделано).
- **2.2 · приёмник — писать хотя бы частично.** Автор хочет, чтобы участники касались самого сервера, но без программирования: пять ключевых строк `tools/receiver.mjs` закомментированы с меткой ▶ и пояснением «зачем», участник раскомментирует (Cmd+/). Пока не раскомментировал — 501 с подсказкой. `--solution` = тот же файл с раскомментированными строками. Магазин PR №19, слайд и README обновлены. Теги — после репетиции, одним заходом.
- **2.3 · задание без цели.** «Поменяй имя, атрибут, статус» — автор: «визуально ничего не понятно, упражнение непонятное». Стало миссией: «доложи о проваленном заказе Sandy-9 руками» — приёмник после каждого спана из `span.json` печатает чек-лист (имя, секунда, статус 2, `order.quantity=20`, `order.rejected`), у каждого пункта — какое поле JSON. Печать: заголовок пачки (сервис, версия, число спанов), колонки, цвета, атрибуты — ещё одна строка ▶. Автор: «когда есть понятная цель — больше похоже на игру». Магазин PR №19, слайд `first-json` переписан.
- **Процесс:** мой тест на копии занял 4318, пока там работал приёмник автора, и я остановил его приёмник по номеру порта. Данные в `.telemetry` не пострадали. Урок записан: перед тестом на фиксированном порту проверять, что он свободен.
- **Правило автора: до «The APM agent, by hand» — всё руками, ни пакета, ни APM-агента, ни обзервера.** Нарушали: в файлах задания («next-observe sends JSON», «Be the APM agent», `dev:v1/v2`, «stop the observer»), слайд «Two packages, one letter apart» стоял в части 1, на `part-2`/`black-box`/`first-json` — «APM agent», «later the observer». Всё убрано; «Two packages» переехал в часть 3 перед «Good evening, Kevin»; план поправлен.
- **Стандарт для всех заданий (решение автора):** миссия с целью из истории, приёмник/скрипт сам печатает чек-лист (✓ / ✗ с готовой к вставке подсказкой), ★ с выводом, никакого настоящего кодинга — нужные строки закомментированы с «зачем», `--solution` для отставших. Каждое следующее задание сначала превращаем в миссию, потом репетируем.
- **Процесс:** правки в клон репетиции — только через смерженный PR и `git pull` (я копировал файлы — автор: «у других как будет?»; четыре коммита после мержа №19 не попали в master — PR №20).
