# React Native: границы пользовательских метрик

Карточка `framework-native` стоит после перехода от web-кейса и перед новым мобильным расследованием.

> «В React Native мы по-прежнему начинаем с того, чего ждёт пользователь. Это может быть запуск приложения, ответ на действие или плавность движения. Для каждого нужны свои источники и границы. Например, JS callback или React layout не доказывают, что результат уже показан на экране. А времена из native и JS нельзя вычитать, не проверив совместимость часов».

> «Прежде чем выбирать профилировщик, определим действие и то, что пользователь считает результатом. Тогда мы сможем связать техническую работу с опытом человека».
