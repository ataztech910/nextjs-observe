# 27 · Profile once. Check every pull request.

`step: ci-profile-once` · Чтобы не вернулось · **18:30 → 19:15** (0:45)

**На экране:** «Check behaviour and counts, not milliseconds», два правила из двух расследований, 3 / 3 локально.
**Задача слайда:** показать, как обе исправленные ошибки возвращаются через полгода — и ни один отчёт этого не замечает. Отсюда проверка на каждый PR. Главное правило: проверять поведение и счётчики, а не миллисекунды.

## Текст

Обе ошибки исправлены. Но исправление живёт до первого рефакторинга.

Через полгода кто-то переносит страницу на свой сервер — и подключает скрипт как обычный модуль. Кто-то пишет новый экран — и снова забывает отписку в `useEffect`. Ни один отчёт этого не покажет: Lighthouse снова поставит сто, React Profiler снова не увидит рендеров.

Профиль объяснил причину один раз. Чтобы она не вернулась, нужна проверка, которая запускается на каждом pull request.

И важно, что именно проверять. Не миллисекунды. Время на CI-машинах шумит: тест «не больше 12 миллисекунд» будет то падать, то проходить, и через неделю его отключат. Проверяем поведение и счётчики: «ранний клик отсортировал список», «после закрытия экрана — ноль подписок». Они не шумят.

Обе проверки мы проверили так же, как на вебе: на сломанной версии они падают три раза из трёх, на исправленной — проходят три из трёх. Пока локально.
