# 14 · Same early click. Different result.

`step: web-streaming-comparison` · Веб: кнопка есть, кода нет · **8:40 → 9:30** (0:50)

**На экране:** два реальных снимка после раннего клика, рекомендации на обоих ещё грузятся. Слева обычный module — порядок прежний, справа async — отсортировано. Подпись 6/6 и 6/6.
**Задача слайда:** проверить гипотезу так, как договорились на слайде 8: тот же клик, та же страница, то же число — и список должен остаться правильным. Гипотеза подтверждается.

## Текст

Две копии одной страницы. Один и тот же код, одна и та же задержка рекомендаций — три секунды. Разница — одно слово в теге script: слева обычный модуль, справа `async`.

В обеих нажимаем «сначала дешёвые» примерно через 700 миллисекунд. На обоих снимках рекомендации ещё грузятся. *(показать)*

Слева порядок прежний: лампа, блокнот, кружка. Справа — блокнот, кружка, лампа. Отсортировано.

Один снимок ничего не доказывает. Поэтому мы сделали шесть пар и чередовали, какой вариант идёт первым. Обычный модуль: ранний клик потерян шесть раз из шести. `async`: правильный порядок ещё до прихода рекомендаций — шесть из шести.

И то, о чём договорились в начале: список должен остаться правильным. Остался. В конце всех двенадцати прогонов порядок верный, ошибок нет.

Гипотеза подтвердилась. Кнопку держали рекомендации.
