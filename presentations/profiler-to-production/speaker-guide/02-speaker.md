# 02. Спикер — about-me

**Зачем:** объяснить, откуда интерес к измерениям внутри RN-приложений. Бюджет: 45 секунд.

## Что говорить

«Я Андрей, работаю над React Native агентом Dynatrace — SDK, который выполняется внутри приложений.
Поэтому меня интересует не только красивый профиль одного экрана, но и то, как измерять поведение приложения
и стоимость самого измерения. Числа, которые покажу здесь, получены на наших контролируемых стендах».

Дополнительный конкретный пример из рабочего опыта должен дать спикер, если его можно раскрывать.
В материалах такого согласованного production-примера пока нет; не приписываем лабораторные числа клиентам.
