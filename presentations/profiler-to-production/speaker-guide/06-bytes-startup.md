# 06. Одинаковый JavaScript, разный startup — slide-04

**Зачем:** отделить объём скачанного кода от выполняемой работы. Старый бюджет: 4 минуты; предлагаем сократить.

## Что говорить

«Здесь обе конфигурации скачали один и тот же JavaScript, с совпадающими хешами файлов. Размер gzip —
117 765 байт. Но одна конфигурация выполняет больше избыточной работы при старте. Выбранное вычисление занимает
349–354 миллисекунды вместо 1.4–3.2. До первого layout effect приложение доходит за 424–448 миллисекунд
вместо 82–146».

«Это не аргумент перестать следить за bundle size. Это пример того, почему байт недостаточно:
надо увидеть, какая работа реально запускается до нужного пользователю события».

## Что показывать — конкретно

1. Открыть `#step=slide-04`, кадр B. Сначала одинаковые bytes, затем строку selected compute.
2. Показать отдельную строку navigation → first layout effect: это более широкий интервал.
3. При работающем viewer открыть
   `http://127.0.0.1:4341/performance?report=bundle-b-1794566743221-443a`.
   Сопоставить byte evidence и timing, не углубляться в каждую сетевую квитанцию.

Здесь нет видео startup; PNG иллюстрирует приложение и сохранённые числа, а не момент появления первого кадра.

## Доказательство и ограничения

[Кадр B](../graph/src/assets/measurements/B-startup.png),
[источники](../graph/src/assets/measurements/sources.json),
[протокол B](../../../docs/research/performance-observability/EXPERIMENT_B_GATE.md).
Raw/decoded JS — 368 651 B; gzip/encoded — 117 765 B. Все четыре primary pairs сохранили matching bodies.
Локально: `performance-observability/reports/bundle-b-1794566743221-443a/analysis.json` и `analysis.html`.

Это один compiled artifact с 16/6000 redundant passes, а не разные равные по размеру библиотеки.
Конечный вычисленный результат совпадает. Один Mac, четыре пары, диагностические профили отдельно.
Selected compute не включает все imports/setup; layout effect не является paint, TTI или SSR hydration.

**Решение:** оставить компактно. Hydration всё ещё нужно показать отдельным реальным кейсом;
этот кадр нельзя переименовать, чтобы закрыть обещание.
