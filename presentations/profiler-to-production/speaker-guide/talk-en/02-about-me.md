## Script

My name is Andrei. I work at Dynatrace on the React Native agent.

An agent is code that runs inside someone else’s app, on real people’s phones, and records what happens to them.

There’s no profiler running there. No Lighthouse. You only have what you managed to record: someone tapped here, and the result appeared then.

So I don’t start by asking, “Is the app fast?” I ask, “What was this person waiting for—and did they get it?” That question will help us solve the puzzle of that page.

And let me be clear from the start: everything I’m showing today is a lab example I built myself. The tools are real, and the numbers come from actual runs. But these are not customer data.
