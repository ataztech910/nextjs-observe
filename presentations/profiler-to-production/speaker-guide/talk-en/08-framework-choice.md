## Script

Let’s give the task back to the team and ask them to take it in a different order.

First: what was the shopper waiting for? Not “Is the page fast?” but “How long from the click to the sorted list?” That’s one primary number. The team hasn’t measured it yet.

Then: why? Profile that exact interval, from the click to the list, and look for a cause we can test. Not “everything is slow,” but a specific place.

Only then do we fix it. Repeat the same click on the same page and compare the same number. The list must still be correct. A fast but wrong answer doesn’t count.

That’s the path we’ll follow now, step by step.
